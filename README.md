# puffin

The short link for the audience demo in the talk *Your agent returned 200. Was it right?*
(AI Coding Summit, November 17, 2026): **https://nmarrs.github.io/puffin**.

The QR code on the slides points here, and this page forwards to wherever Mission Control (the demo's public
chat) is running. When it isn't running, the page says so. This repository holds only that page: no code from
the demo and no secrets.

To change where it forwards, run `scripts/set-shortlink.sh <url>` (or `--off`) from the demo repo.
