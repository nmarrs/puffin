Your agent returned 200. Was it right?

Nathan Marrs and Jack Gordley, Grafana Labs. The cheat sheet and the links from the talk.

The idea

Every agent response has two statuses. HTTP gives you the first one for free: 200 OK means the request made it there and back. The second one, whether the agent was right, you have to measure.

So keep returning 200 to the client, and record the second status as telemetry.

The codes, and what to measure

Real HTTP status codes, borrowed as names for agent failures. Nothing returns them: each one maps to a signal you can record.

Start Monday with one agent

  1. Export OpenTelemetry from one agent. Metadata only to start. an Agent Observability SDK (Go, Python, TypeScript, Java, .NET), a framework integration, or plain OTLP.
  2. Tag spans with conversation ID, agent name and prompt version. filter conversations by agent and compare versions.
  3. Write one rubric for your scariest failure, and score live traffic with it. an LLM judge as an online evaluation rule.
  4. Send low scores to a human, and keep real failures as tests. a review queue, then promote the conversation to a test case.
  5. Block prompt, model and tool changes that fail the suite. offline experiments, run in CI.

A week of work, not a platform project. Everything here is OpenTelemetry, so it works with any OTLP backend.

Try it on your coding agent

Claude Code exports its own OpenTelemetry metrics and events. Point it at any OTLP endpoint:

export CLAUDE_CODE_ENABLE_TELEMETRY=1
export OTEL_METRICS_EXPORTER=otlp OTEL_LOGS_EXPORTER=otlp
export OTEL_EXPORTER_OTLP_PROTOCOL=grpc
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
# optional: break cost down by repo or team
export OTEL_RESOURCE_ATTRIBUTES="repo=my-repo,team=my-team"

With Grafana Cloud, the agento11y CLI sets it up for you and sends sessions to Agent Observability's Coding agents view, metadata only by default:

brew install grafana/grafana/agento11y
agento11y login      # paste the block from your stack's setup page
agento11y claude     # or: agento11y codex

Codex CLI also takes an [otel] section in ~/.codex/config.toml, and Copilot in VS Code exports traces, metrics and events.
